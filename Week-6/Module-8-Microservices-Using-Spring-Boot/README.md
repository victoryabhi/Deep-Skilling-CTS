# Week-6 Microservices Using Spring Boot

This project is a student-friendly Spring Boot 3 learning workspace for Cognizant Deep Skilling Java FSE Week-6.

## Structure

- Each topic has its own folder with a short explanation and a working Spring example.
- The code uses Java 25, Maven, and Spring Boot 3.
- The project can be run locally with Maven.

## Run the project

```bash
mvn spring-boot:run
```

Open http://localhost:8080 to explore the sample endpoints.
