# Topic 9.4: React ES6 and JSX

## Description
This module demonstrates JavaScript ES6 features and their syntax within JSX (JavaScript XML). React relies heavily on ES6 conventions for writing clean, expressive component code.

## Key Concepts Covered
- **Arrow Functions**: Syntactical shortcut for writing function expressions.
- **Destructuring**: Conveniently unpacking properties from objects or arrays.
- **Template Literals**: Injecting variables directly into strings using backticks.
- **JSX Expressions**: Placing Javascript statements and calculations inside `{}` within markup.

## Code Explanation
The accompanying `Es6Jsx.jsx` file implements a course info card showing Cognizant Deep Skilling modules. It uses ES6 destructuring, template literals, and map methods to transform data directly inside JSX.
