# Topic 9.3: React Components and Props

## Description
This module covers React Components and Props. Components are the building blocks of a React application. Props (short for "properties") are the read-only parameters passed from a parent component down to a child component to make them reusable and dynamic.

## Key Concepts Covered
- **Functional Components**: Creating reusable presentation or logical UI units.
- **Props (Properties)**: Passing data from parent to child.
- **Default Props**: Defining fallback values for props when none are specified.
- **De-structuring Props**: Accessing props variables directly inside component arguments.

## Code Explanation
The accompanying `ComponentsProps.jsx` implements a list of user profile cards. A parent component (`ComponentsProps`) passes different data (name, role, status) as props to a child component (`UserProfileCard`), showing how components can be reused with varying data.
