# Module 9: React SPA (Single Page Application) - Cognizant Deep Skilling

This directory contains the source code, interactive dashboard, and modular exercises for **Module 9: React SPA** of the Cognizant Deep Skilling program (Java FSE Track).

## Folder Structure
Each directory contains a distinct, fully working React component and an explanatory `README.md` file suitable for educational/training reviews:

- [9.1-Introduction-to-SPA](./9.1-Introduction-to-SPA/) — Client-Side routing logic using React state transitions.
- [9.2-Introduction-to-React](./9.2-Introduction-to-React/) — Basic Counter demonstrating virtual DOM re-renders and React state.
- [9.3-React-Components-and-Props](./9.3-React-Components-and-Props/) — Reusable Functional Components receiving and displaying custom React props.
- [9.4-React-ES6-and-JSX](./9.4-React-ES6-and-JSX/) — Standard JSX syntax mixed with modern JS ES6 expressions (destructuring, arrow functions, template literals).
- [9.5-React-Events](./9.5-React-Events/) — React Event handlers (`onClick`, `onChange`, `onSubmit`, and synthetic events).
- [9.6-Conditional-Rendering](./9.6-Conditional-Rendering/) — Rendering views conditionally using Ternary Operators, logical AND `&&`, and variables.
- [9.7-React-Lists-and-Keys](./9.7-React-Lists-and-Keys/) — Rendering list data mapping arrays and explaining the role of unique `key` tags.
- [9.8-React-Forms](./9.8-React-Forms/) — Controlled components, input validation, and managing multi-field form objects.
- [9.9-Calling-API-with-React](./9.9-Calling-API-with-React/) — Fetching dynamic remote profile details with `fetch` inside the `useEffect` hook.

## How to Run the Project Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v16.0.0 or higher recommended).

### Steps to Run
1. Open your terminal and navigate to the project directory:
   ```bash
   cd Module-9-React-SPA
   ```
2. Install all dependencies:
   ```bash
   npm install
   ```
3. Launch the local Vite development server:
   ```bash
   npm run dev
   ```
4. Open the displayed URL (usually `http://localhost:5173`) in your browser to inspect the interactive training dashboard!
